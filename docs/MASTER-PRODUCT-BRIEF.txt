MASTER PRODUCT DEVELOPMENT PROMPT

DARIYA — Smart Property Management for Moroccans Living Abroad

1. PROJECT OVERVIEW

Build a modern PropTech startup called DARIYA, a digital property management platform based in Morocco.

DARIYA helps Moroccans living abroad (MRE — Marocains Résidant à l’Étranger) remotely manage their houses, apartments, rental properties, maintenance, expenses, tenants, and property documents.

The platform combines:

* Property management software
* Remote property inspections
* Maintenance coordination
* Rental management
* Financial tracking
* A network of trusted local service providers
* AI-powered property assistance

The main concept:

“Your home in Morocco. Managed from anywhere.”

DARIYA is not simply a real estate listing website. It is a complete digital property management service.

The first launch market is Tangier, Morocco, with future expansion to Nador, Oujda, Fes, Casablanca, Rabat, and other Moroccan cities.

9. TECHNICAL ARCHITECTURE

Recommended stack:

Frontend:
Next.js + TypeScript

UI:
Tailwind CSS + shadcn/ui

Backend:
Supabase

Database:
PostgreSQL

Authentication:
Supabase Auth

Storage:
Supabase Storage

Charts:
Recharts

Forms:
React Hook Form + Zod

Deployment:
Vercel

Architecture should be modular and scalable.

Create reusable components.

Use secure server-side authorization.

Implement database Row Level Security so customers can only access their own properties and records.

Do not expose secret keys in frontend code.

12. SECURITY AND TRUST

Because the platform manages private property information, implement:

* Secure authentication
* Role-based authorization
* Private document storage
* Signed URLs for sensitive files
* Audit logs
* Input validation
* Secure file upload
* Data isolation between customers
* Privacy-conscious notifications
* Backup strategy

Design the platform to support applicable Moroccan data protection requirements, including Law 09-08 and CNDP obligations.
